# Что это?

DNS-клиент для командной строки. ОС: Linux.

# Что умеет?

Умеет формировать запросы и обрабатывать ответы, учитывая все стандартные секции DNS-сообщений:

- Секция запросов
- Секция ответов
- Секция авторитетных серверов
- Дополнительная секция

Позволяет вести работу с рядом типов записей:

- A (IPv4)
- AAAA (IPv6)
- PTR (домен)
- NS (авторитетные записи)
- CNAME (псевдоним)

Поддерживается сжатие имён. 

Есть возможность установить таймаут. По умолчанию - 1000 мс.

# Как пользоваться?

```bash
./dns
 -h, --host <хост>                  имя для поиска
[-q, --qtype a|aaaa|ptr|cname|ns]   тип записи
[-v, --verbose]                     подробный вывод
[-p, --port <порт>]                 порт DNS-сервера
[-s, --server <ip>]                 ip-адрес DNS-сервера
[-t, --timeout <мс>]                время таймаута
```

Пример вывода:

```bash
root@WiseWalkerDesktop:/mnt/d/dns# ./dns -h yandex.ru
Секции ответов
----------------------------------
77.88.44.55
----------------------------------
77.88.55.88
----------------------------------
5.255.255.77
----------------------------------
```

```bash
root@WiseWalkerDesktop:/mnt/d/dns# ./dns -h 77.88.44.55 -q ptr
Секции ответов
----------------------------------
yandex.ru
----------------------------------
```

В корневом каталоге есть исполняемый файл `dns`. Можно использовать его.

# Техническое описание

При разработке использовался C++ 20. Использовался GNU-компилятор.

В реализации не задействованы никакие сторонние зависимости, исключительно стандартная библиотека и POSIX-сокеты.

Для удобства деконструкции написаны структуры для заголовков каждого из сообщений в стеке:

- `IpHeader` - заголовок IP-пакета
- `UdpHeader` - заголовок UDP-сегмента
- `DnsHeader` - часть DNS-сообщения с фиксированной длиной и структурой
- `QuerySection` - структура секции запроса в DNS-сообщении
- `AnswerSection` - структура секции ответа в DNS-сообщении. Подходит также для секции авторитетного сервера и дополнительной секции.
- `DnsRequest` - вспомогательная структура для упорядочивания хранимых данных о DNS-запросе. Имеет функцию по вычислению размера запроса и перевода в и из сетевого порядка байтов.
- `DnsResponse` - аналогичная структура для ответов.
